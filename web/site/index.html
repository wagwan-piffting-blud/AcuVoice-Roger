How does this work?

AcuVoice (Fonix, ~1998-99) is a concatenative unit-selection synthesizer: it turns text into a string of phonetic units, then stitches together short µ-law audio snippets from a 160 MB soundbank. Re-implementing its ~300 KB linguistic front-end (number/date/abbreviation expansion, a pronunciation dictionary, letter-to-sound rules, prosody) would risk subtly changing how Roger speaks. So instead of rewriting it, this page runs the original 32-bit Windows DLL unmodified.

A purpose-built x86 interpreter (with a tiny PE loader and ~70 Win32 API shims) was written in C and compiled to WebAssembly with Emscripten. It loads avcore_acu.dll, runs its C-runtime startup and DllMain, and calls the engine's _txtstr_to_sndbuf export - exactly as a native program would. The emulator's output is byte-for-byte identical to the desktop voice. Audio is 8 kHz mono µ-law, decoded to PCM and played via the Web Audio API. Everything runs in a Web Worker; the soundbank is fetched in cached 256 KB blocks via range requests.
